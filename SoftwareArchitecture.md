All of the code for GenePool Swimbots is in the "GenePool" directory. Inside of that directory are the following:

1. Index.html
2. css folder
3. images folder
4. simulation folder
5. js folder

The first three should be self-explanatory to anyone experienced in web development. 

The simulation folder contains all the files that handle swimbot physics, genetics, foodbits, and various other aspects of configuring and running the simulation.
